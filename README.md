# Home Essentials

Home Essentials is a production-oriented Amazon Associates publishing website for US shoppers. It combines a public editorial catalog with a protected administration area for products and buying guides.

The deployment architecture is deliberately simple:

- Vercel runs the Next.js application.
- Hosted Supabase provides PostgreSQL, authentication, Row Level Security, and optional media storage.
- The private admin publishes content directly to Supabase.
- The public website reads only content allowed by RLS.
- Verified Amazon Associates links render directly; there is no checkout, cart, payment system, link cloaker, or intermediate redirect.

Docker is not required for local website development, hosted database setup, or Vercel deployment.

## Included

- Responsive public homepage, categories, product catalog, product details, buying guides, About, Contact, Privacy, Terms, and Affiliate Disclosure pages.
- Protected Supabase email/password sign-in with database-backed `admin` and `editor` roles.
- Product list, filters, drafts, publishing states, duplicate/archive/delete actions, private preview, a six-input Quick Add form, and a detailed editor for optional refinements.
- Structured buying-guide editor with safe paragraph, heading, list, image, product, and related-guide blocks.
- Strict Amazon.com URL, ASIN, and tracking-ID validation.
- Publishing guards for complete content, active categories, verified links, and compliant price data.
- Exact Amazon Associates disclosure: “As an Amazon Associate I earn from qualifying purchases.”
- Dynamic metadata, sitemap, robots, manifest, Pinterest sharing, and JSON-LD without invented ratings.
- Supabase migrations, RLS policies, Storage policies, category seed data, automated tests, and deployment documentation.

No products are seeded. Add only real, verified product information after your Amazon Associates account and links are ready.

## Run locally

Requirements: Node.js 22.13 or newer and npm.

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

Open `http://127.0.0.1:3000`.

Without Supabase values, the public design still opens with truthful empty states and the admin explains what configuration is missing. Add these values to `.env.local` to enable sign-in and database content:

```dotenv
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLIC_PUBLISHABLE_KEY
NEXT_PUBLIC_SITE_URL=http://127.0.0.1:3000
NEXT_PUBLIC_CONTACT_EMAIL=you@example.com
```

The public publishable key is safe to use in the browser because the database enforces RLS. Do not add a service-role key; this application does not require one.

## Hosted Supabase and Vercel

1. Create a hosted Supabase project.
2. Apply every SQL file under `supabase/migrations` in filename order, then apply `supabase/seed.sql`.
3. Create the first Auth user and matching `public.profiles` row by following `docs/first-admin.md`.
4. Add the four environment variables above to Vercel. Use the final HTTPS URL for `NEXT_PUBLIC_SITE_URL`.
5. Import the repository into Vercel and deploy with the default Next.js settings.

The remote CLI path is also supported and does not require Docker:

```powershell
npx supabase@3.0.0 link --project-ref YOUR_PROJECT_REF
npx supabase@3.0.0 db push --dry-run
npx supabase@3.0.0 db push
```

See `docs/deployment.md` for the complete checklist.

## Product workflow

1. Sign in at `/admin/login`.
2. Open Products and choose **Add product**.
3. Enter the product name, category, a short original recommendation, an authorized image URL, and the exact Amazon.com affiliate URL generated by SiteStripe.
4. Confirm that you generated and checked the affiliate link. Quick Add derives the page slug and ASIN from your entry, and generates the initial descriptions, image alt text, and search summary.
5. Choose **Publish product** when every required field is ready, or **Save draft** to finish later. Editors without affiliate-link permission can save drafts for an administrator to review.
6. Use the detailed editor after saving if you want to refine optional specifications, highlights, SEO fields, or other supporting details.
7. A published product appears on the public site immediately; no code change or redeployment is needed.

Quick Add does not fetch or scrape Amazon catalog content. Product names, recommendations, and images must be accurate, original or authorized, and verified by the publisher.

Prices remain hidden unless they come from an approved Amazon catalog API workflow and include a recent verification timestamp. The admin form intentionally does not accept a manually typed live price.

## Important files

- `src/app` — public and protected application routes.
- `src/components` — public, admin, product, and article interfaces.
- `src/services` — database queries and authorized mutations.
- `src/lib/affiliate/url.ts` — Amazon.com link validation.
- `supabase/migrations` — schema, RLS, Storage, triggers, indexes, and safe public-link policy.
- `docs/database-setup.md` — hosted database setup.
- `docs/amazon-compliance.md` — operational compliance checklist.
- `docs/deployment.md` — Vercel launch instructions.

## External account requirements

To complete a live launch, supply your own hosted Supabase project, Vercel account, final domain, contact email, Amazon Associates tracking ID, and verified product links. Amazon catalog retrieval is not performed by scraping. A future automated product importer should use an Amazon-approved catalog API only after the account is eligible and credentials are available.
